# ColorPickerTool 🎨

A beautiful, fast, and fully functional **Online Color Picker & Palette Generator** built with HTML, Tailwind CSS, and React (via CDN). 

No build tools required — just open `index.html` and it works instantly!

![Color Picker Preview](https://color-picker-website.onrender.com/)

## ✨ Features

- **Live Color Picker** with HEX & RGB values
- **Extract Color Palette** from any image (Upload or URL)
- **One-click copy** for HEX and RGB codes
- **Beautiful UI** with Tailwind CSS
- **Fully Responsive** – works great on mobile & desktop
- **Client-side only** – No backend, no data collection
- Privacy & Contact pages included
